### Template: NixOS container-internal config (evaluated INSIDE the container)
###
### Copy to:
###   configurations/configs/specific/container/nixos-container/<container-name>/container-config.nix
###
### ⚠️ Required signature: { inputs, stateVersion, pkgs, username }
### - pkgs        = HOST pkgs (the container's own pkgs has no overlay:
###                 pkgsUnstable does not exist there). Passed by the framework.
### - stateVersion= host NixOS version (26.05)
### - username    = container SSH user (sshUser option of the declaration)
### - inputs      = host flake inputs (unused in this template)
###
### Real example:
###   configurations/configs/specific/container/nixos-container/opencode-sandbox/container-config.nix
